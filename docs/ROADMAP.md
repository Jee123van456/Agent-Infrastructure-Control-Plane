# TYLERDECK FUTURE ROADMAP

## V1 Roadmap (Next 3 Months)
- TypeScript / Node.js SDK (`@tylerdeck/sdk`)
- Google Gemini native API wrappers & streaming ingestion
- Slack, Discord, and Webhook alert destinations
- Prompt Hub versioning & A/B testing playground

## V2 Roadmap (6 Months)
- Automated AI Root-Cause Analysis (LLM Agent diagnosis of failure clusters)
- Agent Replay & Trajectory Sandbox
- Continuous Evaluation Test Suite runner (CI/CD integration)
- Fine-grained PII redaction engine with custom regex rules

## V3 Roadmap (12 Months)
- Shared Organizational Memory & Agent Governance
- Production policy enforcement SDK sidecar proxy
- Enterprise SOC2 / SAML SSO / Kubernetes Helm Charts
